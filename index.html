变量：给信息贴上标签

在 Python 中，使用 = 把右边的值交给左边的变量名。以后只要使用这个名字，就能找到对应的数据。变量名应清楚表达它保存了什么。

# 创建三个不同类型的变量
learner = "小明"  # str 字符串
lessons = 3      # int 整数
is_ready = True # bool 布尔值

print(learner, "已完成", lessons, "课")
